# Requisitos del proyecto

**Construcción del Almacén de Datos (Ingeniería de Datos)**

## Objetivo

Desarrollar un almacén de datos moderno utilizando SQL Server para consolidar información de ventas, permitiendo generar reportes analíticos y facilitar la toma de decisiones informadas.

## Especificaciones

| Especificación | Descripción |
|---|---|
| Fuentes de datos | Importar información de dos sistemas de origen (ERP y CRM), proporcionados mediante archivos CSV. |
| Calidad de los datos | Limpiar y resolver los problemas de calidad de los datos antes de realizar los análisis. |
| Integración | Combinar ambas fuentes en un único modelo de datos, fácil de usar y diseñado para consultas analíticas. |
| Alcance | Trabajar únicamente con el conjunto de datos más reciente. No se requiere historial. |
| Documentación | Documentación clara del modelo de datos para interesados del negocio y equipos de análisis. |
